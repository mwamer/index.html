Sign in to edit

Cloudflare looks after the sign-in, so there is no key to copy and nothing to set up on a second device. It emails you a one-time code, and the session lasts 24 hours.

  1. Press Sign in. A tab opens on api.wesamamer.com.
  2. Type the email address you are authorised with, then the code Cloudflare emails you.
  3. That tab will say you are signed in. Close it.
  4. Come back here and press Check again.

Not signed in. The entries below can still be read from this computer, but nothing reaches the live site until you sign in.

Manage Editors

Owner-only. Add an editor and they start pending, so they can sign in and see the panel but cannot publish until you activate them. The owner account cannot be suspended or removed.
